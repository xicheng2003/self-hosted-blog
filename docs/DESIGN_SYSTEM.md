# AuraDawn 设计规范

这份规范用于约束 `self-hosted-blog` 与 `home_page` 的共同视觉语言。两个项目合并前，新增组件也应优先复用这里定义的 token、图标和交互规则，避免形成第三套样式。

## 字号阶梯

博客界面使用 `app/globals.css` 中的字号 token，不再为单个组件新增零散的小字号：

- `--font-size-caption: 0.75rem`（12px）：日期、分类、标签、图片说明等元信息，也是可见文字的最小字号；
- `--font-size-small: 0.875rem`（14px）：导航链接、摘要、表格、代码块和辅助正文；
- `--font-size-body-small: 0.9375rem`（15px）：表单、次级说明和较紧凑的阅读文字；
- `--font-size-body: 1rem`（16px）：默认正文与品牌文字。

标题可以按页面层级继续使用更大的固定值或 `clamp()`，正文中的图标和行内代码可以使用相对单位；除此之外，任何可见文字都不得小于 `--font-size-caption`。移动端沿用同一字号下限，不通过缩小文字解决横向空间不足。

首页“最近文章”区域内，重点文章和其后的三篇最近文章必须共用同一套标题与摘要排版，包括字号、字重、行高和字距；标题统一使用 `clamp(1.4rem, 3.5vw, 1.85rem)`。桌面端三篇最近文章左侧日期的垂直中点必须与右侧标题首行的垂直中点对齐，移动端日期仍独占一行。重点关系通过版式、元信息和操作提示表达，不再额外增加标题或摘要的字号层级。

订阅模块在所有断点整体居中：说明文字、RSS 链接、订阅表单和反馈信息共用页面中轴；邮箱输入内容继续按书写方向起始侧对齐，不能因模块居中而改成居中输入。

## 导航与版权

- 导航左侧保留独立的 `AuraDawn` 品牌字标及原有链接目标，不把版权文案移入导航，也不因页脚样式调整而改变导航结构。
- 导航与页脚的品牌字标统一使用主文字色、衬线阅读字体、常规字重、`-0.025em` 字距及 `AuraDawn` 的原始大小写；两处允许使用不同字号，但其余视觉样式必须一致。
- 导航品牌字标在两个项目和所有断点统一使用 `1.25rem`（20px），页脚版权中的品牌字标保持 `1rem`（16px）。
- 导航栏吸附在视口顶部并保留高斯模糊：使用半透明表面、`20px` 模糊和 `140%` 饱和度；不使用边框、悬浮卡片式圆角或阴影，仅通过透明度和模糊与滚动内容区分，使其与页面背景融合。
- 三个导航链接在两个项目中统一使用宋体字族、常规字重和 `0.875rem`（14px）；桌面端整组固定在导航栏的水平中心。
- `42rem` 以下隐藏三项桌面导航，改为右侧 `2.5rem × 2.5rem` 纯图标汉堡按钮；按钮不使用边框、圆角、背景容器或阴影。展开菜单靠右对齐，并复用导航栏的半透明模糊表面、边框和颜色 token。
- 汉堡图标使用 `24 × 24` viewBox、`currentColor`、`1.55` 圆角线宽及三条等长水平线；展开时平滑变形为关闭图标，并服从 `prefers-reduced-motion`。按钮必须提供本地化的 `aria-label`、`title`、`aria-expanded` 和 `aria-controls`，菜单项点击或按下 Escape 后关闭。
- 页脚版权保持 `© AuraDawn since 2023` 的完整内容；其中只有 `AuraDawn` 沿用导航品牌字标除字号外的样式，`©` 与 `since 2023` 继续使用小号界面元信息样式。
- 页脚中的版权与备案文字统一使用主文字色，与品牌字标颜色一致；主题及辅助控件继续使用自身的交互状态颜色，不强制继承页脚文字色。
- 页脚版权单独占据第一行；ICP 与公安备案共同位于第二行，两条备案保持基线对齐且不换行。
- 所有断点都将“版权＋备案”视为一个完整信息块，其垂直中心必须与右侧主题及辅助控件的垂直中心对齐；移动端同样保持左右并列，不改为上下分行。
- 移动端备案行不得横向滚动、折行、截断或隐藏；信息块以自身容器宽度驱动备案文字和图标的响应式缩放，只有与右侧控件并列导致空间不足时才允许低于全局最小字号。主题与语言控制器保持完整尺寸并继续与其并列。
- `self-hosted-blog` 从 `content/site.ts` 的 `siteConfig.name` 读取品牌名；`home_page` 从 `src/App.tsx` 的 `NAME` 读取品牌名，避免页脚和导航出现不同拼写。

## 链接图标

链接旁的图标使用项目内 SVG 组件，不使用 Unicode 箭头或第三方图标库。这样可以让笔画粗细、对齐方式和深浅主题下的颜色保持一致。

- 统一使用 `16 × 16` 的 `viewBox`；
- 线条继承 `currentColor`，默认 `stroke-width: 1.35`；
- 端点与转角使用圆角，默认不填充；
- 图标必须与可见文字同时出现，装饰性 SVG 使用 `aria-hidden="true"` 与 `focusable="false"`；
- 右上箭头统一复用 `components/icons/external-arrow.tsx`，路径与 `home_page` 的快速链接一致；
- RSS 标识统一复用 `components/icons/rss-icon.tsx`，只有语义必要的订阅圆点允许实心填充；
- `RSS feed` 链接的下划线必须从 RSS 图标左缘连续延伸至文字末尾，覆盖图标与文字之间的间距；右上箭头不纳入下划线。
- 图标尺寸使用相对文字的 `em`，正文中的右上箭头为 `0.8em`，RSS 图标为 `0.9em`。
- 快速链接悬停时整体上移 `1px`；右上箭头沿自身方向位移，RSS 图标只做一次轻微缩放反馈。动效使用 `180ms` 与项目 easing，并服从 `prefers-reduced-motion`。

右上箭头既可表示外部链接，也可作为卡片或列表的“打开/继续阅读”动作提示。方向不同的页面级导航（例如返回、下一页）继续使用水平箭头，不混用右上箭头。

## 主题与辅助控件

- AUTO、DARK、LIGHT 必须连接成一个三段式主题控件，共用一圈方形圆角外框；分段之间只使用细分隔线，不拆成三个悬浮按钮，也不使用胶囊形外观。
- 每个主题分段在桌面固定为 `2.5rem × 2.5rem`，移动端为 `2rem × 2rem`；控件外框统一使用 `0.45rem` 圆角，与博客订阅输入框和订阅按钮一致。
- 选中分段使用凸起表面与内描边，悬停分段仅做轻微底色反馈，不能破坏连体轮廓；键盘焦点必须清晰可见。
- `home_page` 的语言按钮位于主题控件旁，作为独立的同尺寸方形圆角按钮，与三段主题控件保持间距。
- 三个主题分段只显示 SVG 图标：系统主题使用带明暗分区的显示器，深色主题使用月牙与星芒，浅色主题使用太阳；图标统一采用 `24 × 24` viewBox、`currentColor` 和 `1.55` 圆角线宽。
- SVG 仅负责视觉表达并标记为装饰性元素，按钮必须提供本地化的 `aria-label` 与 `title`，不能依赖图标本身传达无障碍名称。
- 选中态指示层在三段控件底部以 `280ms` 沿水平方向滑动，图标同步做轻微缩放；动效使用项目 easing，并服从 `prefers-reduced-motion`。

## 跨项目复用

在最终合并 `home_page` 与博客时，只保留一份 `ExternalArrow`、`RssIcon`、`MenuIcon` 和对应 CSS。合并前如需调整路径、笔画或尺寸，应同时检查两个项目中的快速链接、文章列表、正文外链、RSS 入口与移动导航。

页面外壳使用 grid 时，必须显式设置 `min-width: 0` 与 `grid-template-columns: minmax(0, 1fr)`；作为直接 grid item 的导航、内容区和页脚也必须允许收缩。移动端文章标题使用 `overflow-wrap: anywhere` 作为长英文、数字及连续字符的断行兜底，不能让页脚备案、文章横行或长标题的最小内容宽度反向撑大整个页面。
